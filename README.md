# 让它记住你
## 一个不靠形容词的记忆插件

### 一

先说个谁都碰过的事。

你今晚跟它聊了一整晚，明天关掉窗口再开，它看着你，像从没认识过。

不是它笨。是它脑子里只有一张桌面——摊满了就是摊满了，一收拾，全没了。

我们不想换它的脑子。我们只是给它添了一个本子。

### 二

装上之后，你会慢慢发现这些：

昨天说过的事，今天提一句，它接得上。

你说过「这个别再问我了」，它真的不再问。

隔了半个月回来，它还记得你在意什么。

它不会突然变聪明。它就是——记得住。

### 三

怎么做到的，三句话：

它只收新说的话，旧账不重抄。（增量指纹，听过的不再进队列）

它的本子分三层：桌上摊着的、本子上写着的、柜子里锁着的。（窗口／近记忆／深柜，冷热分层，原文一个字不删）

本子会瘦，瘦掉的是字，不是事。（定期压成一句，原文落柜，用 `memory_detail` 按关键词翻得回来）

说到底，我们让它记的不是资料，是锚。哪天它的脑子整个换掉，靠这些锚，它还认得你。

### 四

它不做什么：

不联网打听你，不上传你的聊天，不翻你还没开口的那些地方。

不装懂，不编。没记到的事，它老实说没记到。

这些不是漂亮话——是我们真的没让它做。

### 五

写给谁：

写给愿意花点时间把 AI 养熟的人。偶尔问问天气的，装了也没用。

也写给上班已经很累的人——装完你就可以忘了它，它自己记账，你不用管。

**本子会旧，字会瘦，事不会丢。**

## 给想深究的人

代码一行没加密。阈值、提示词、切段规则，全在明面上。

- 攒够 **1200 字**压一批，压的粒度跟批次对齐，不跨批复读。
- 压之前先剔掉平台塞进来的索引、纪要、注入块——本子不照镜子，只写真话。
- **最近两轮不压**。你正在说的这段，它不动手。
- 压话的模型二选一：手里有便宜的云端 key 就走云端，几秒一压；没有就本地 ollama，7b 跑得动，不花钱就是慢。
- 压出来的东西分「规矩」和「事情」两份写；三层全空就跳过不写——宁可这本子薄，也不塞垃圾。

许可证只拦一件事：改完藏着，不给别人看。

## 怎么装

**一、给谁用**

给 AstrBot 用。要挂得上 `on_llm_request` 钩子的版本，太老的装了不干活。

**二、放哪儿**

整个文件夹丢进 `data/plugins/`，目录名 `astrbot_plugin_memory_whale`。

**三、压话用什么模型**

两条路，挑一条：

- **本地**（不花钱）：装 [ollama](https://ollama.com)，`ollama pull qwen2.5:7b`，约 4.7G，跑在 `127.0.0.1:11434`。压 1200 字十来秒，机器差可以换 3b，快但用词糙。
- **云端**（快、稳）：填一把便宜档的 key，几秒一压，账单一分钱级别。

没配够也不至于崩：抓得到话、攒得起来，就是压不动，它会老实报拿不到模型。

**四、翻开**

重载插件，随便聊两句。想立刻看到结果，发：

```
/m3_dump
```

它会告诉你收到了多少条、攒了多少字、本子里现在有几条。

## 配置（全部可以不写）

面板上填了就以面板为准，面板留空的才看 `config.json`：

```json
{
  "data_dir": "",
  "my_name": "",
  "nicks": { "平台用户ID": "想显示的名字" },
  "anchor": true,
  "anchor_text": "",
  "auto": true,
  "show_date": false,
  "detail_vault": true
}
```

- `data_dir`：本子放哪。空＝插件目录下的 `data/`。
- `my_name`：**它自己叫什么**。想叫几个都行，逗号隔开；留空就叫「小助手」。压话时它把「助手」「AI」都认成这个名字。
- `nicks`：把平台给的原始 ID 换成好认的名儿，省得本子里全是 `ou_1a2b3c`。
- `anchor` / `anchor_text`：开对话时补一小段定心话，管的是「它记得自己记着事」。不覆盖你原来的人格。
- `auto`：`false` 就只收不压，全靠你自己喊 `/m3_go`。
- `show_date`：本子里的日期平时不亮，要分先后时再叫出来。
- `detail_vault`：压完把原文整份沉进柜子。关了省地方，但就只能记个骨架。

## 命令

| 命令 | 干什么 |
|---|---|
| `/m3_new` | 看队列攒了多少、还差多少字够压 |
| `/m3_go` | 现在压一批（只压攒着的，压完清队） |
| `/m3_all` | 硬压：连最近两轮一起压（平时不用） |
| `/m3_dump` | 看它抓到了哪些话，自己核对 |
| `/m3_clear` | 清队列，指纹留着——老话不会被重新收 |
| `/m3_anchor` | 看定心话开着没、写了什么 |
| `/m3_date` | 让本子带日期说话 |
| `/m3_wash` | 把旧账里「用户说／助手说」那种腔调按说明书重写一遍 |
| `/m3_import 路径` | 把别人家的老本子导进来（.md/.json/.jsonl/.txt） |
| `/m3_backup` | 整份存一份，回你路径 |
| `/m3_restore [存档名]` | 列存档 / 回到某一份 |
| `/m3_task` | 任务卡：`列` / `新 标题` / `记 标题 一句话` / `完 标题` |

`/m3_wash` 和 `/m3_import` 动手前会自己先存一份，不用你记。

## 给模型的六个工具

装上以后它自己会调：

- `memory_note`：往本子里记一条
- `memory_recall`：翻本子，全翻或只看规矩／只看事情
- `memory_lookup`：搜关键词
- `memory_detail`：想不起前因后果时，按关键词把当时原话捞回来
- `memory_folk`：记人和人之间的关系（谁是谁）
- `memory_task`：手头的活单独开一张卡，记进度和卡点，做完归档——卡也能被搜到

记不记、什么时候翻，由它自己判断。插件只负责本子可靠。

## 它记在哪

全在一个文件夹里，没有第二处：

- `state.json`：见过的消息指纹、还没压的队列
- `vault/群合并/`：**所有群聊共用一本**（一条鱼不分身）；私聊各是各的，永远不混
- `vault/<私聊>/`：本子上的人、事、规矩，外加落柜的原文
- `tasks/<任务>/`：任务卡（`card.md` 卡面、`log.md` 流水），做完标完成
- `out/`：每次压完的原始结果，可翻
- `backup/<时间_原因>/`：整份复印，里面有说明

想搬家、想备份、想核对，全在这一个文件夹。

## 几个坑

1. **日志里出现 `Loading plugin ...` 不等于启用**。真正说了算的是 `data/cmd_config.json` 里的 `plugin_set` 名单——名字不在里面，文件在、日志有，就是不干活。
2. **群聊的上下文窗口比私聊小得多**（群里可能只十几条）。不攒就是出窗口即丢，这也是这个插件存在的理由。
3. **别在有人正经干活的时候跑本地 7b 压测**，风扇会叫。
4. 命令是一字不差匹配的，`/m3_ go` 中间多一个空格就不认。
5. **改了 `my_name` 要重载插件**才生效。
6. **本子会分冷热**：七天没提算温、三十天没提算冷，冷的退出每轮目录（不删、搜得到，被翻一次就回热）。
7. **本子有上限**（规矩 120 条、事情 1200 条），满了挤掉最老的骨架——所以分级存比攒着更重要。

## 隐私

- 本子、队列、指纹全在 `data/`，只在你机器上。
- `data/`、`config.json`、`*.bak*` 全在 `.gitignore` 里，不会被顺手推上去。
- 走本地模型时，插件一个包都不往外发；走云端时，只把要压的那一段文字发给你的模型服务商，别的什么都不带。

## 我们接定制

这插件**不收钱**。

放出来是给人用的，不是拿来卖的。装完能用一辈子，我们不找你要一分。

但它只有一版，而人不止一种。

有人怕它忘了人，有人怕它忘掉一句话里的分量，有人要它死也不许忘掉某一个名字。

通用版给不了这个。通用版只能谁都照顾一点——它记的事实是对的，分量是平的。

**定制版是按你怕的那一处，单独加一道护栏。**你不说，我们不加；你说了，那道门就锁死。

我们不报价，也不在这写怎么做。手艺这东西，说细了就不值钱了。

**欢迎真正有深度的玩家来定制。**

怎么找到我们：仓库的 Issue 一直开着。开口不用客套，说清你怕它忘掉什么，就够了。

至于抹掉名字、说成自己写的——这条不用谈。
